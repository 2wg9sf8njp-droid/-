# 夜のニュースを配信する

## 0. 準備

1. Skill ツールで `ai-study-hub` を読み込み、その `references/schema.md` と `references/writing.md` を読む。
2. `ArtifactData` と `WebSearch` を ToolSearch で読み込む。
3. 今日の日付を日本時間で確かめる(`TZ=Asia/Tokyo date +%F`)。今日の `entries` にすでに news があれば、二重に作らずにそれを返して終わる。

## 1. ニュースを集める

直近24〜48時間の AI・システム関連ニュースを探す。検索は同じターンでまとめて投げる(日本語・英語の両方で)。例:

- 「AI ニュース <今日の日付>」「生成AI 発表 今日」
- "AI news today", "LLM release", "AI agent announcement", "open source model release"
- 開発の道具: "GitHub", "developer tools AI", "security vulnerability AI"

結果が薄い、古い、あやしいときは `mode: "extended"` で探し直す。

**選び方**(3〜5本):

- 一次情報(公式ブログ、発表、論文、信頼できる報道)があるものを優先する。噂やまとめ記事だけのものは外す
- 新モデルや新機能、AI エージェントや開発ツール、セキュリティ、規制や社会の動きなど、分野が偏らないようにする
- ユーザーが学んだ知識(`concepts`)とつながるものを1本以上入れると、復習になる
- 日付を必ず確かめる。古い記事を「今日のニュース」として出さない

## 2. 内容を作る

`writing.md` のニュースの型に沿って書く。

- 「何が起きたか」は事実だけ。数字・日付・名前は出典どおりに書く
- 「なぜ重要か」は、レベル b のユーザーの言葉で説明する
- 既存の concepts とつながる部分は名前を出して結びつける(例: 「前に学んだサンドボックスが、ここでも使われています」)
- 最後に「今日のひとこと」を書く

**復習**: `nextReview <= 今日` の concepts から1問を、その `reviewChoices` を使って `quiz` に「【復習】」付きの選択式で入れる。ニュースの理解を確かめる選択式の問題も1〜2問入れる(形式は schema.md の quiz。4択、正解の位置はばらけさせる)。新しく concepts に登録する用語には `reviewChoices` と `reviewAnswer` を必ず付ける。

**実践課題**: ニュースの内容を試せるものがあるときだけ1件(新しい機能を触ってみる、など)。無理に作らない。

## 3. 記録する(batch で一度に)

- `entries/<日付>-news` を set(`kind: "news"`, `slot: "night"`、`sources` 必須)
- 新しい重要用語があれば `concepts` に set(多くても2個)。既存の知識が登場したら `entryIds` に追加
- 出題した復習知識の stage と nextReview を進める
- 実践課題があれば `practice` に set

## 4. 返答する

`writing.md` の「会話への返答」の形で短く返す。見出しは3〜5本すべて並べる。
